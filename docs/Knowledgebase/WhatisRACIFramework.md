# What is RACI Framework?

**RACI** is a framework used to clearly define roles and responsibilities within a process or project. A RACI matrix aligns teams on ownership, prevents overlap or gaps, and supports smooth execution in multi-stakeholder environments. It identifies:
- **Responsible (R)** for performing the work
- **Accountable (A)** for the final outcome 
- **Consulted (C)** for expert input   
- **Informed (I)** about status and results

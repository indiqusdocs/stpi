# Integration Details and Feature List

The feature list and integration details section provides an overview of the core capabilities and integration aspects of the Object Storage service. It outlines the standard and service-specific integration touchpoints that enable seamless provisioning, management, and monitoring of storage resources.
It also highlights the key features available in the service, helping you understand its functionality and manage your object storage environment effectively.

This section covers the following topics:
- [Standard Integration Touchpoints](#standard-integration-touchpoints)
- [Specific Integration Touchpoints](#specific-integration-touchpoints)
- [Feature List](#feature-list)

## Standard Integration Touchpoints
The following standard integration touchpoints describe the key integration points that enable the provisioning, management, and monitoring of Object Storage services within the Ananta Cloud platform:

- **Account Creation**: As end-users opt for the AS3, an account is created on the Cloudian Hyperstore. This account lets you manage and configure your Cloudian HyperStore deployment, access administrative features, and control various aspects of your storage environment.
- **Cataloguing:** This service is part of the catalogue, for example, the service provider configures from where to deliver the service and at what price to deliver the service.
- **Usage Reporting:** All usage data is available through the UI. You can log in to Ananta Cloud at any time to view consumed resources and the associated usage details.

## Specific Integration Touchpoints

The following specific integration touchpoints define the core interactions that enable you to provision, manage, and access Object Storage resources through the Ananta Cloud platform:
- **Create Buckets:** You can create buckets with unique names, following the naming convention mentioned on Ananta Cloud.
- **Add Objects:** You can add objects to your respective buckets using Ananta Cloud.
- **Manage Service on Object Storage Platform:** Detailed object and bucket management is done via the object storage platform admin panel, which can be accessed directly from Ananta Cloud.
## Feature List

The following feature List highlights the key capabilities of the Ananta Object Storage service. These features enable you to create, manage, and access object storage resources through the Ananta Cloud platform while ensuring compatibility, ease of use, and efficient storage management:

- **Single S3 Zone:** Currently, on Ananta Cloud, only single S3 zone support is available.
- **Buckets View:** On the Ananta Cloud UI, you can log in and view all the distinct buckets you have created.
- **Bucket Creation:** You can create buckets with unique names following the naming convention mentioned on the Ananta Cloud UI.
- **Bucket Edit:** You can edit the already created Buckets at any point in time by logging in to the Ananta Cloud UI.
- **Object Creation:** You can directly upload objects from the Ananta Cloud console.
- **Object Deletion:** You can delete the objects associated with the bucket straightforwardly and hassle-free.
- **Object Access:** There is a Manage service button on the UI; to open a new tab, click on it with the Object Storage Platform URL, and you can log in with your username and password, and you can access, manage, and configure things related to your storage environment.
- **S3 API Compatibility:** Ananta Object Storage Service is fully compatible with the S3 API.
- **Option to Unsubscribe from the Service:** You can easily unsubscribe from the service at any time from the Ananta Cloud UI only.

# Requirements for Autoscale

The following are the prerequisites of autoscale:
- Ananta now uses the native Autoscale feature of ACS. This feature is available with ACS version 4.18.0.0 onwards. 
- Create at least one VPC.
- Create one network tier with a public load-balancing tier in the VPC.
- Assign one IPv4 address to the load balancer.
